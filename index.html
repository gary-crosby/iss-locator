About

This web app shows the current position of the International Space Station (ISS) on a 3D globe.

Position data comes from the WhereTheISS.at API and refreshes every 10 seconds. The globe is drawn with globe.gl and three.js.

Created by Gary Crosby for the Web Technologies module of the MSc Computer Science at Sheffield Hallam University.
