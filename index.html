About

This web app displays the real time position of the International Space Station (ISS) on a 3D globe.

Every 10 seconds, the app gets the ISS position data from that API at api.wheretheiss.at and plots it as a red dot against a 3D globe of the Earth. The globe is drawn using globe.gl and three.js.

The app was designed and created by Gary Crosby for the Web Technologies module of the MSc Computer Science at Sheffield Hallam University.
