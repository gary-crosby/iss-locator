# International Space Station (ISS) Tracker app

## Background

The International Space Station (ISS) Tracker is a one-page web app that continuously displays the real time position of the International Space Station (ISS) on a rendered 3D globe of the Earth.

I created the International Space Station (ISS) Locator web app to fulfill the requirements of an assignment for SHU's MSc Computer Science 'Web Technologies' module.

## Install

Put all three files in the same folder on a web server.
